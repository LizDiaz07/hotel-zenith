# Hotel ZENITH — Sitio Web

Sitio web multipágina de Hotel ZENITH, hotel de negocios ubicado en Tehuacán, Puebla, México.

## Stack técnico
- React + TypeScript + Vite
- Tailwind CSS v4
- React Router
- Web3Forms (formulario de contacto)

## Despliegue
Alojado en Vercel, dominio gestionado en GoDaddy.
